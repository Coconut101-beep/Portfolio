## Typography
- Font: Georgia, "Times New Roman", serif (all text)
- Weight: regular (400) for everything, headings included
- Line height: 1.6

| Element | Size |
|---|---|
| Body text | 16px |
| Page title (h1) | 24px |
| Section heading (h2) | 18px |
| Sub-heading (h3) | 16px, italic |
| Top bar (Email, LinkedIn, Following) | 14px |
| Name in top bar | 16px |
| Following list | 12px, muted |
| Book title | 24px, centred |
| Book author | 14px, italic, muted |
| Book note | 15px, relaxed line height |
| Quote | italic, thin left rule |
| Placeholders | italic, muted, in [brackets] |

## Links
Deep Tiffany, underlined (2px offset). The current tab shows in ink, no underline, with an "— " in front.

## Layout & sizes
- Page padding: 24px (32px on wide screens); tabs sit at the far left
- Tab column: 160px wide, stays in place while scrolling
- Content column: max 576px (Bookshelf is wider)
- Profile photo: 44px circle, top right
- Book page: max 720px; cover 120px, tilted −8°
- Corner radius: 8px
- Motion: tabs slide 4px right when hovered (0.2s); menus fade in
